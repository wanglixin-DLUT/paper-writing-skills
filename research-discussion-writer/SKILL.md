# Research Discussion Writer

Use this skill to write or revise a Discussion section that moves from results to meaning without outrunning the evidence.

This skill is part of the writing system:

- `content_analysis.md` supplies evidence, limitations, failed or suspicious runs, contribution candidates, and claim boundaries.
- `writing_blueprint.md` supplies target-reader strategy, literature positioning, Discussion move map, certainty strategy, and terminology decisions.
- A Results draft or result evidence map supplies the findings that can be interpreted.

## Core Principle

The Discussion should not merely repeat the Results. It revisits key results in order to explain what they mean, how they relate to existing knowledge, what they contribute, what they cannot yet support, and where the work leads.

Interpret boldly enough for the reader to see the contribution, but not so boldly that the claims detach from evidence.

## Start Here

1. Look for `content_analysis.md`, `writing_blueprint.md`, and any Results draft or result evidence map in the active project/manuscript directory and nearby parent directories.
2. If `content_analysis.md` exists, use it for:
   - contribution candidates and evidence support
   - limitations, failed runs, and missing experiments
   - scope of claims and safer wording
3. If `writing_blueprint.md` exists, use it for:
   - Discussion move map
   - target-paper conventions for limitations, applications, and future work
   - literature mapping and target-reader assumptions
4. If no Results evidence exists, ask for it or draft only a Discussion outline.

## Workflow

1. Diagnose the task.
   - New Discussion, revision, limitation section, implication framing, literature comparison, future work, or combined Results/Discussion.

2. Select the Discussion structure.
   - Use `references/discussion_models.md`.
   - Decide where to place contribution, result interpretation, literature comparison, limitations, applications, and future work.

3. Build the interpretation map.
   - Use `references/interpretation_and_claims.md`.
   - For each key result, define observed result, interpretation, evidence strength, literature link, limitation, and implication.

4. Draft the Discussion.
   - Use `references/discussion_workflow.md`.
   - Start with contribution or key finding if target papers do so.
   - Move from key results to meaning, then to comparison, limitations, and applications.
   - Keep literature citations functional.

5. Calibrate modal strength.
   - Use `references/modal_strength_and_limits.md`.
   - Use cautious language for possible mechanisms, future uses, and limited evidence.

6. Revise for alignment.
   - Use `references/discussion_revision_checklist.md`.
   - Check that the Discussion answers the Introduction gap, interprets Results accurately, and does not overclaim.

## Output Modes

- `outline`: produce paragraph-level Discussion moves.
- `draft`: produce a complete Discussion.
- `revision`: rewrite or restructure an existing Discussion.
- `claim calibration`: soften, strengthen, or justify claims.
- `limitations`: write limitations and future work.
- `literature comparison`: map findings to prior work.
- `handoff`: produce a Discussion plan for conclusion or abstract.

## Output Standards

A good Discussion:

- States the study's contribution clearly.
- Revisits only key results and moves beyond them.
- Maps findings to prior work or knowledge.
- Explains implications while preserving evidence boundaries.
- Discusses limitations that matter.
- Suggests future work linked to actual limitations or opportunities.
- Uses modal verbs and cautious language when needed.
- Aligns with `content_analysis.md`, `writing_blueprint.md`, Results, Introduction, Abstract, and Conclusion.
